# Формат строки:  x y z [измерение] [радиус] [имя]
# После координат всё необязательно и порядок не важен:
#   измерение — minecraft:the_nether, nether, end ... (по умолчанию любое)
#   радиус    — число (по умолчанию из настроек модуля, 2 блока)
#   имя       — всё остальное (по умолчанию координаты)
#
# Примеры:
# 100 64 -250
# 0 70 0 minecraft:the_nether Портал
# 50 80 50 minecraft:overworld 3.5 База
# 10 65 10 Алмазы

100 64 -250 Деревня
0 70 0 minecraft:the_nether Портал
50 80 50 minecraft:overworld 3.5 База
